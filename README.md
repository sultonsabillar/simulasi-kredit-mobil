# Simulasi Kredit Mobil

Project sederhana untuk simulasi kredit mobil berbasis web.

## Cara Menjalankan

1. Buka file `index.html` di browser.
2. Masukkan data simulasi kredit pada form yang tersedia.
3. Klik "Hitung Angsuran" untuk melihat hasil perhitungan dan jadwal angsuran.

## Fitur
- Input data kredit (nomor kontrak, nama, harga mobil, DP, tenor, tanggal mulai)
- Perhitungan pokok utang, bunga, dan angsuran per bulan
- Tabel hasil perhitungan dan jadwal angsuran
- Tampilan sederhana dengan Bootstrap

---

**Catatan:**
- Semua perhitungan dilakukan di sisi client (browser)
- Tidak membutuhkan backend/server
